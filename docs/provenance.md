# Project provenance

Tracepoint was developed in this workspace from the inspection-notebook requirements discussed with Afreen. The React interface, branding mark, illustrative SVG schematic, domain workflow and local API were written for this project. No complete third-party application or UI template was imported.

The project deliberately uses third-party building blocks: React, Vite, Mastra, Zod, Mozilla PDF.js, pdf-lib and Bolna's official browser SDK. Integration shapes and SDK usage follow their public documentation. These are dependencies and API examples, not a copied application; their own licenses still apply.

The downloadable demonstration schematics are published by Arduino and SparkFun. They are third-party source documents, not drawings created by Tracepoint. Their original attribution remains in the displayed/exported documents. The homepage product screenshots were captured from Tracepoint itself during local testing and contain clearly labelled demo observations.

Craft's public website was viewed on 24 October 2026 as a reference for generous spacing and a product image revealed during scrolling. No Craft source code, images, branding, copy or product screenshots were imported. Tracepoint keeps its own palette, structure, content and product imagery.

This records what was used in this build. It is not a claim that no similar inspection product or voice workflow exists elsewhere, nor an exhaustive external similarity or legal review.
