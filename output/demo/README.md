# Tracepoint typed demo

`tracepoint-typed-demo.mp4` is a real continuous Edge recording at 15 fps with system playback audio only. No microphone was captured. Typed source requests use Mastra and Groq; spoken readback uses browser speech synthesis, not Bolna. Wispr dictation and a two-way Bolna conversation are not demonstrated.

The demo shows source zoom, animated U5A circle and C9 underline, a reviewable note written beside C9, explicit confirmation, recovery of the saved note after refresh, and a fresh PDF/JSON report snapshot. All saved observations are explicitly marked DEMO TEST and do not assert a verified physical defect. Original source PDFs remain unchanged.
